b01 · apollonius median theorem

두 변의 길이를
중선 하나가
붙잡고 있다

삼각형의 한 변을 반으로 접고, 그 접힌 자리와 마주 보는 꼭짓점을 이어 봅니다. 이 선(중선)의 길이는 자를 대지 않아도 세 변의 길이만으로 정해집니다. 그런데 그 관계는 길이끼리가 아니라 제곱끼리 더할 때만 보입니다. 왜 하필 제곱인지를 따라가 봅니다.

먼저 준비물

이 자료는 고1 과정보다 앞에 놓인 것입니다. 필요한 것은 세 가지뿐이고, 셋 다 중학교에서 이미 만난 것들입니다.

피타고라스 정리
(Pythagorean theorem)		직각삼각형에서 (밑변)² + (높이)² = (빗변)²두 점 사이의 거리를 제곱으로 계산할 때
곱셈 공식(x + m)² = x² + 2mx + m²
(x − m)² = x² − 2mx + m²		더했을 때 2mx가 지워지는 것을 보일 때
중점(midpoint)선분을 똑같은 길이로 나누는 점이 자료 전체의 조건

중선(median)은 삼각형의 한 꼭짓점과, 마주 보는 변의 중점을 이은 선분입니다. 꼭짓점이 셋이니 중선도 셋입니다. 여기서는 그중 하나만 봅니다.

이름에 대하여. 우리나라와 일본에서는 이 정리를 흔히 파포스(파푸스, Pappus)의 중선정리라고 부르지만, 다른 나라에서는 아폴로니오스(Apollonius)의 정리라고 부릅니다. 같은 정리를 가리키는 다른 이름입니다. 이 자료에서는 오해가 없도록 중선정리라고만 쓰겠습니다. ⚠️ 이름의 유래는 백과사전 서술을 따랐고 원문 대조는 아직 하지 않았습니다 · refs/math-notes.md 참조

숫자 하나로 먼저 봅니다

세 변이 13, 9, 10 인 삼각형을 가져오겠습니다. BC = 10 의 중점을 M이라 하면 BM = MC = 5 입니다. 그리고 이 삼각형에서 중선 AM 의 길이는 정확히 10 입니다. (왜 10인지는 잠시 뒤에 계산으로 나옵니다.)

이제 두 가지를 각각 계산해 보겠습니다. 한쪽은 M을 전혀 쓰지 않고, 다른 한쪽은 M만 씁니다.

  1. AB² + AC² = 13² + 9² = 169 + 81 = 250 M이 등장하지 않는다
  2. 2(AM² + BM²) = 2(10² + 5²) = 2 × 125 = 250 A에서 M까지, B에서 M까지만 썼다

두 값이 같습니다. 우연처럼 보이지만 어떤 삼각형을 가져와도 그렇습니다. 이것이 중선정리입니다.

가로·세로 눈금 모두 한 칸 = 1 로 같은 배율입니다. A의 위치는 세 변의 길이에서 계산한 값입니다 — A(9.4, √80.64). 초록은 중점 M과 관련된 것, 파랑은 처음 주어진 것입니다.

여기서 틀린다 — 제곱을 빼먹는다. 중선정리는 AB + AC = 2(AM + BM) 이 아닙니다. 위 삼각형으로 확인하면 왼쪽은 13 + 9 = 22, 오른쪽은 2(10 + 5) = 30 으로 전혀 다릅니다. 길이끼리는 이런 관계가 없고, 제곱해서 더할 때만 관계가 생깁니다.

왜 성립하는가 — M을 원점에 놓는다

이유는 딱 한 줄로 끝납니다. 중점 M을 원점에 놓고 BC를 가로축에 눕히는 것입니다. 그러면 B와 C는 원점에서 서로 반대 방향으로 같은 거리에 놓입니다. 이것이 "중점"이라는 조건의 전부이고, 정리가 성립하는 이유의 전부이기도 합니다.

M을 원점에 놓았으니 BM = MC = m 이라 하면 B(−m, 0), C(m, 0) 입니다. A는 아무 데나 있어도 되므로 A(x, y) 라고 두겠습니다.

가로·세로 눈금 모두 한 칸 = 1 로 같은 배율입니다. 그림은 m = 5, A(1.5, 8) 로 그렸지만 라벨은 문자입니다 — 어떤 m, x, y 를 넣어도 아래 계산은 그대로입니다.

  1. AB² = (x + m)² + y² = x² + 2mx + m² + y² B(−m, 0)까지의 거리를 제곱했다
  2. AC² = (x − m)² + y² = x² − 2mx + m² + y² C(m, 0)까지의 거리를 제곱했다
  3. AB² + AC² = 2x² + 2y² + 2m² +2mx 와 −2mx 가 서로 지워진다 — 여기가 전부다
  4. = 2(x² + y²) + 2m² 묶어 놓고 보면
  5. = 2(AM² + BM²) AM² = x² + y², BM = m 이었으니까

지워진 2mx 가 이 정리의 정체입니다. B와 C가 M에서 정확히 반대쪽으로 같은 거리에 있었기 때문에, x가 든 항이 부호만 다른 쌍으로 나와 사라진 것입니다. 남은 것은 x 와 y 가 제곱으로만 들어간 AM² 과, M이 정한 m² 뿐입니다.

성립 조건. 위 계산에서 쓴 것은 M이 BC의 중점(BM = MC)이라는 것뿐입니다. 그래서 AB² + AC² = 2(AM² + BM²) 는 A, B, C가 평면 위의 점이고 M이 BC의 중점이기만 하면 언제나 성립합니다. A가 어디에 있든(예각·둔각·직각 어느 삼각형이든) 상관없고, 놀랍게도 세 점이 한 직선 위에 있어 삼각형이 되지 않아도 성립합니다. 계산 어디에서도 "삼각형이다"라는 사실을 쓰지 않았기 때문입니다. (직선 위에 있으면 y = 0 인 경우일 뿐입니다.) tools/verify-math.py 의 check_b01_theorem() 이 격자점 배치 117,649가지(그중 일직선 12,049가지)를 전수 확인합니다
여기서 틀린다 — 중점이 아닌 점에 갖다 쓴다. 이 식은 M이 중점일 때만의 식입니다. 각의 이등분선이나 높이의 발처럼 "그럴듯한 점"에 그대로 쓰면 틀립니다. 앞의 삼각형(13, 9, 10)에서 A에서 BC에 내린 수선의 발 H로 해 보면 AH² = 80.64, BH² = 88.36 이라 2(AH² + BH²) = 338 이고, 이는 AB² + AC² = 250 과 다릅니다. 중점이 아니면 2mx가 지워지지 않습니다.

다른 얼굴 — 중선을 두 배로 늘리면 평행사변형

중선 AM을 M 너머로 똑같은 길이만큼 더 늘려 점 D를 잡아 봅니다. 그러면 M은 AD의 중점이면서 동시에 BC의 중점이 됩니다. 두 대각선이 서로를 이등분하는 사각형은 평행사변형(parallelogram)이므로, ABDC는 평행사변형입니다.

가로·세로 눈금 모두 한 칸 = 1 로 같은 배율입니다(그림1과 같은 삼각형을 20px/단위로 줄여 그렸습니다). 갈색은 원래 삼각형에 없던 보조선입니다 — 답이 아니라 도구입니다.

평행사변형에서는 네 변의 제곱의 합 = 두 대각선의 제곱의 합 이 성립합니다(평행사변형 법칙). 여기에 AD = 2AM, BC = 2BM 을 넣으면

  1. 2(AB² + AC²) = AD² + BC² BD = AC, DC = AB 이므로 네 변의 제곱의 합은 2(AB² + AC²)
  2. = (2AM)² + (2BM)² = 4AM² + 4BM² M이 두 대각선을 반씩 나눈다
  3. AB² + AC² = 2(AM² + BM²) 양변을 2로 나눴다
이건 증명이 아니라 같은 사실의 다른 얼굴입니다. 평행사변형 법칙 자체를 증명하려면 결국 앞 절과 똑같은 계산(좌표를 잡고 제곱을 전개하는 것)을 해야 합니다. 그러니 이 그림은 "중선정리를 새로 증명했다"가 아니라 "중선정리와 평행사변형 법칙은 같은 말이었다"로 읽는 것이 맞습니다. 자료에서 증명은 앞 절의 좌표 계산 하나뿐입니다.

써먹기 — 세 변을 알면 중선이 나온다

앞에서 "중선 AM이 10"이라고 그냥 말했는데, 사실은 잴 필요가 없었습니다. 중선정리를 AM² 에 대해 풀면 됩니다. BM = BC/2 이므로 BM² = BC²/4 입니다.

  1. AB² + AC² = 2(AM² + BM²) 중선정리 (M은 BC의 중점)
  2. = 2AM² + BC²/2 BM² = (BC/2)² = BC²/4 을 넣고 2를 곱했다
  3. 2AM² = AB² + AC² − BC²/2 AM²만 남기려고 옮겼다
  4. AM² = (2AB² + 2AC² − BC²) / 4 양변을 2로 나누고 분모를 맞췄다

13, 9, 10 짜리 삼각형에 넣어 보면 AM² = (2·169 + 2·81 − 100)/4 = 400/4 = 100, 그래서 AM = 10 입니다. 자를 대지 않고 나왔습니다.

두 번째 줄은 이미 알던 사실입니다. 직각삼각형에서 ∠A = 90° 이면 피타고라스 정리로 AB² + AC² = BC² 이므로, 중선정리에 넣으면 2(AM² + BM²) = BC² = (2BM)² = 4BM² 이고 따라서 AM² = BM², 곧 AM = BM = BC/2 입니다. "직각삼각형에서 빗변의 중점은 세 꼭짓점에서 같은 거리에 있다"가 중선정리의 한 조각이었던 셈입니다. AM = BM 은 길이가 모두 양수라서 제곱을 벗길 수 있습니다
여기서 틀린다 — BM 자리에 BC를 넣는다. 2(AM² + BC²) 로 쓰면 13, 9, 10 삼각형에서 2(100 + 100) = 400 이 되어 250과 맞지 않습니다. 괄호 안에 들어가는 것은 반쪽 BM입니다. BC로 쓰고 싶다면 형태가 바뀝니다 — AB² + AC² = 2AM² + BC²/2 (= 200 + 50 = 250). 두 식은 같은 식이고, 2와 1/2 자리를 헷갈리면 바로 틀립니다.

직접 움직여 보기 — 그리고 역은 성립할까

이번에는 다른 삼각형을 씁니다. A(8, 6), B(0, 0), C(6, 0) 이라서 AB² = 100, AC² = 40, 왼쪽 값은 항상 140 입니다. M을 BC를 따라(그리고 그 바깥까지) 밀어 보며 오른쪽 2(AM² + BM²) 이 어떻게 변하는지 보세요.

왼쪽은 M과 아무 상관이 없습니다. 움직이는 것은 오른쪽뿐입니다. 두 값이 같아지는 자리를 찾아보십시오 — 한 군데가 아닙니다.

가로·세로 눈금 모두 한 칸 = 1 로 같은 배율입니다. M은 선분 BC를 넘어서까지 움직입니다. 판정 상자가 초록이면 중점에서 성립한 것, 분홍이면 중점이 아닌데도 성립한 것입니다.

역은 성립하지 않습니다

중선정리는 "M이 중점이면 등식이 성립한다"입니다. 그 반대, 즉 "등식이 성립하면 M은 중점이다"는 거짓입니다. 위 슬라이더에서 M(5, 0) 을 찾아보세요.

왜 두 군데일까요. 오른쪽에서 왼쪽을 뺀 값을 t로 정리하면 이차식이 나오고, 이차식이 0이 되는 자리는 최대 두 군데이기 때문입니다.

  1. (오른쪽) − (왼쪽) = 2((8 − t)² + 6² + t²) − 140 AM² = (8 − t)² + 6², BM² = t²
  2. = 4t² − 32t + 200 − 140 전개해서 정리했다
  3. = 4(t − 3)(t − 5) 0이 되는 자리는 t = 3 과 t = 5, 두 군데

중점은 t = 3 하나뿐인데 등식이 성립하는 자리는 둘이므로, 등식만 보고 중점이라고 말할 수 없습니다. 참고로 t = 5 는 우연이 아니라 A의 위치에 따라 정해지는 자리입니다.

여기서 틀린다 — "역도 당연히 성립하겠지". t = 5 인 점을 보면 정체가 드러납니다. 이 점에서는 BM = 5, MC = 1 로 둘이 다릅니다. 그래서 B와 C를 바꿔 쓴 식 2(AM² + MC²) = 2(45 + 1) = 92 는 140과 맞지 않습니다. 진짜 중점에서는 BM = MC 라서 어느 쪽으로 써도 같은 값이 나옵니다. "BM으로도 성립하고 MC로도 성립한다"까지 요구해야 비로소 M은 중점입니다. (BM² = MC² 이고 길이는 양수이므로 BM = MC.)

남는 것

  • 중선정리는 제곱끼리의 관계다. M이 BC의 중점이면 AB² + AC² = 2(AM² + BM²). 길이끼리 더한 관계는 성립하지 않는다.
  • 성립하는 이유는 상쇄 하나다. M을 원점에 놓으면 B와 C가 −m, m 으로 놓여 +2mx 와 −2mx 가 지워진다. 중점이 아니면 지워지지 않는다.
  • 역은 성립하지 않는다. 등식이 성립하는 점은 중점 말고 하나 더 있다(위 삼각형의 M(5, 0)). "성립한다 ⇒ 중점이다"라고 쓰면 틀린다.
써먹을 형태로 한 번 더. AM² = (2AB² + 2AC² − BC²)/4 — 세 변을 알면 중선의 길이가 나옵니다. 성립 조건은 딱 하나, M이 BC의 중점이라는 것입니다.
