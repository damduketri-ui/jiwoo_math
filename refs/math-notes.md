## 01 이차함수의 최대·최소

### 쓴 정의·정리

| 항목 | 내용 | 성립 조건 | 확인 |
|---|---|---|---|
| 이차함수 | y = ax² + bx + c | **a ≠ 0** · a, b, c는 실수 | 교과서 공통 |
| 완전제곱식(표준형) | y = a(x − p)² + q | a ≠ 0 | 교과서 공통 |
| 꼭짓점 | (p, q) = (−b/2a, −D/4a) | a ≠ 0 | 유도 (아래) |
| 대칭축 | 직선 x = −b/2a | a ≠ 0 | 유도 |
| 판별식 | D = b² − 4ac | 계수가 **실수**일 때만 근의 개수를 판정한다 | 교과서 공통 |
| 최대·최소 | a > 0 → x = −b/2a 에서 최솟값 −D/4a, 최댓값 없음<br>a < 0 → 같은 x 에서 최댓값 −D/4a, 최솟값 없음 | 정의역이 실수 전체 | 유도 |
| 제곱의 부호 | 모든 실수 t 에 대해 t² ≥ 0, 등호는 t = 0 일 때만 | **실수 범위에서만** (복소수에서는 i² = −1) | 교과서 공통 |

### 유도 (계산 근거)

```
ax² + bx + c                                       (a ≠ 0)
= a(x² + (b/a)x) + c                               x가 든 항에서 a를 묶는다
= a(x² + (b/a)x + (b/2a)² − (b/2a)²) + c           절반의 제곱을 더하고 뺀다
= a(x + b/2a)² − a·b²/(4a²) + c
= a(x + b/2a)² − b²/(4a) + c
= a(x + b/2a)² + (4ac − b²)/(4a)
= a(x + b/2a)² − D/(4a),        D = b² − 4ac

⇒ p = −b/2a,  q = −D/4a
```

`a > 0` 일 때 q < 0 ⟺ D > 0 이고, 이것이 "D > 0 이면 서로 다른 두 실근"의 도형적 의미다.
(접시 바닥이 x축 아래에 있어야 곡선이 x축을 두 번 가로지른다.)
`a < 0` 일 때는 부등호가 뒤집혀 q > 0 ⟺ D > 0 이다.
→ `tools/verify-math.py` `check_01_discriminant()` 가 a·b·c 격자 2704가지를 전수 확인한다.

### 자료에 실은 값

```
y = x² − 6x + 5 = (x − 3)² − 4
  꼭짓점 (3, −4) · 대칭축 x = 3 · D = (−6)² − 4·1·5 = 16 · 근 x = 1, 5

제한된 범위 (a = 1 > 0, 꼭짓점 x = 3)
  0 ≤ x ≤ 2   꼭짓점 밖   최대 5 (x=0)   최소 −3 (x=2)
  2 ≤ x ≤ 6   꼭짓점 안   최대 5 (x=6)   최소 −4 (x=3)
  4 ≤ x ≤ 6   꼭짓점 밖   최대 5 (x=6)   최소 −3 (x=4)
  ※ [0,2]와 [4,6]은 대칭축 x=3에 대한 거울상이라 값이 같고 위치만 뒤바뀐다
```

→ `tools/verify-math.py` `check_01_restricted()` 가 공식을 쓰지 않고 구간을 40만 점 훑어
   위 값과 대조한다. 꼭짓점이 범위 밖인 구간에서 최대·최소가 항상 양 끝점에서 나오는지도 확인한다.

### 그림의 좌표 매핑

그림2  x∈[−9,9], y∈[−10,10]   X(x) = 240 + 22x   Y(y) = 250 − 22y   (곡선은 스크립트가 계산)
그림3  x∈[−1,8], y∈[−5.5,7]   X(x) =  76 + 30x   Y(y) = 240 − 30y

| 평행사변형 법칙 | 네 변의 제곱의 합 = 두 대각선의 제곱의 합 | 평행사변형일 것 | 중선정리와 **동치** (아래) |

**삼각형일 필요가 없다.** 아래 유도 어디에서도 "삼각형이다"를 쓰지 않는다.
세 점이 한 직선 위에 있어도(= y = 0 인 경우) 그대로 성립한다.
→ `check_b01_theorem()` 이 격자점 배치 117,649가지(그중 일직선 12,049가지)를 전수 확인한다.

### 유도 (계산 근거)

```
M을 원점에, BC를 x축에 놓는다. M이 중점이므로 BM = MC = m 이라 하면
  B(−m, 0),  C(m, 0),  A(x, y)

AB² = (x + m)² + y² = x² + 2mx + m² + y²
AC² = (x − m)² + y² = x² − 2mx + m² + y²
──────────────────────────────────────────  더하면 ±2mx 가 상쇄된다
AB² + AC² = 2x² + 2y² + 2m²
          = 2(x² + y²) + 2m²
          = 2(AM² + BM²)          ∵ AM² = x² + y² (M이 원점), BM = m

※ 상쇄가 일어나는 이유는 B와 C의 x좌표가 −m, +m 으로 부호만 다르기 때문이다.
   이것이 "중점"이라는 조건의 전부다. 중점이 아니면 2mx 항이 남는다.
```

중선의 길이 공식:

```
AB² + AC² = 2(AM² + BM²),  BM = BC/2 ⇒ BM² = BC²/4
AB² + AC² = 2AM² + BC²/2
     2AM² = AB² + AC² − BC²/2
      AM² = (2AB² + 2AC² − BC²)/4
검산: (2·13² + 2·9² − 10²)/4 = (338 + 162 − 100)/4 = 100 → AM = 10
```

`2AB² + 2AC² − BC² ≥ 0` 은 삼각형이 되는 세 수라면 자동이다
(BC < AB + AC 이고 (AB + AC)² ≤ 2(AB² + AC²) 이므로).
→ `check_b01_median_formula()` 가 세 변 1~14 전수로 확인한다.

### 역은 성립하지 않는다 (이 챕터의 핵심 반례)

```
"AB² + AC² = 2(AM² + BM²) 이면 M은 BC의 중점이다" — 거짓.

B(0,0), C(a,0), A(h,k), M(t,0) 으로 두면
  (오른쪽) − (왼쪽) = 4t² − 4ht + 2ah − a² = 0
  t = [4h ± √(16h² − 16(2ah − a²))]/8 = [h ± |h − a|]/2
  ⇒ t = a/2 (중점)   또는   t = h − a/2
  두 근이 겹치는 것은 h = a (A가 C 바로 위) 인 경우뿐이다.

자료의 반례: A(8,6), B(0,0), C(6,0) → a = 6, h = 8
  t = 3 (중점) 과 t = 5 두 곳에서 등식이 성립한다.
  (오른쪽) − (왼쪽) = 4t² − 32t + 60 = 4(t − 3)(t − 5)
  t = 5 에서 BM = 5, MC = 1 로 서로 다르다.

역을 고치려면: BM으로도, MC로도 성립할 것을 요구하면 된다.
  2(AM² + BM²) = 2(AM² + MC²) ⇒ BM² = MC² ⇒ BM = MC (길이는 양수) ⇒ M은 중점.
  실제로 t = 5 에서 2(AM² + MC²) = 2(45 + 1) = 92 ≠ 140.
```

→ `check_b01_converse()` 가 근의 공식을 쓰지 않고 t를 완력으로 훑어 근이 정확히 두 개(3과 5)임을
   확인하고, 일반형 `t = BC/2` · `t = (A의 x좌표) − BC/2` 도 여러 삼각형에서 대조한다
   (두 근이 겹치는 경우 포함).

### 평행사변형으로 보기 — 증명이 아니라 같은 사실

```
D = 2M − A (중선 AM을 M 너머로 같은 길이만큼 연장)
  ⇒ M이 AD와 BC를 모두 이등분 ⇒ ABDC는 평행사변형 ⇒ BD = AC, DC = AB

평행사변형 법칙:  AB² + BD² + DC² + CA² = AD² + BC²
  좌변 = 2(AB² + AC²),  우변 = (2AM)² + (2BM)² = 4AM² + 4BM²
  ⇒ AB² + AC² = 2(AM² + BM²)
```

**주의:** 평행사변형 법칙 자체를 증명하려면 결국 위와 같은 좌표 계산이 필요하다.
그러므로 이것은 독립된 증명이 아니라 **같은 사실의 다른 얼굴**이고, 자료에도 그렇게 적었다.
자료에서 증명은 좌표 계산 하나뿐이다.

## B02 두 점을 지나는 직선 (기본편)

### 쓴 정의·정리

| 항목 | 내용 | 성립 조건 | 확인 |
|---|---|---|---|
| 기울기(slope) | m = (y₂ − y₁) / (x₂ − x₁) | **x₁ ≠ x₂** (분모 ≠ 0) | 교과서 공통 |
| 점-기울기 꼴 | y − y₁ = m(x − x₁) | 위와 같음 · (x₁, y₁)은 직선 위의 아는 점 | 유도 (아래) |
| 두 점 꼴 | y − y₁ = ((y₂−y₁)/(x₂−x₁))(x − x₁) | x₁ ≠ x₂ · 두 점은 서로 다를 것 | 위 둘을 합친 것 |
| 기울기-절편 꼴 | y = mx + b, b = y₁ − m·x₁ | 위와 같음 | 괄호를 푼 것 |
| 일차함수 | y = ax + b 에서 **a ≠ 0** | a = 0 이면 상수함수 | 교과서 공통 |
| 수직선 | x = x₁ — 함수가 아니다 | x₁ = x₂ 인 경우 | 교과서 공통 |

### 유도 (계산 근거)

```
직선 위의 '떠도는 점' (x, y) 를 잡는다.

① 아는 점 (x₁, y₁) 과의 계단 비율:  (y − y₁)/(x − x₁)      [x ≠ x₁ 일 때만 정의됨]
② 같은 직선이므로 이 값은 m 과 같다:  (y − y₁)/(x − x₁) = m
③ 양변에 (x − x₁) 을 곱한다:          y − y₁ = m(x − x₁)
④ ③은 x = x₁ 에서도 참이다(양변이 0) → ①에 뚫려 있던 구멍이 메워진다
⑤ m 에 (y₂−y₁)/(x₂−x₁) 을 넣으면 두 점만으로 쓴 식이 된다

기준점을 (x₂, y₂) 로 바꿔도 같은 직선인 이유:
  y₁ − m·x₁ = y₂ − m·x₂  ⟺  y₂ − y₁ = m(x₂ − x₁)  ← m 의 정의 그 자체
```

**기울기가 두 점 선택과 무관한 이유**: 직선 위 두 점으로 만든 계단들은 서로 닮은 직각삼각형이라
세로:가로 비가 같다. 거꾸로 재면 분자·분모가 모두 −1배가 되어 값이 그대로다.
→ `check_b02_slope_wellposed()` 가 직선 76개 · 점쌍 10,336가지를 전수 확인한다.

### 역도 성립한다 (B01과 대비되는 지점)

```
"직선 위의 점 ⇒ 식을 만족" 과 "식을 만족 ⇒ 직선 위의 점" 이 모두 참이다.
식 y − y₁ = m(x − x₁) 의 해집합이 곧 그 직선이기 때문.
→ '세 점이 한 직선 위에 있는가'를 대입만으로 판정해도 되는 근거가 이것이다.
※ B01(중선정리)에서는 역이 거짓이었다. 매번 따로 따져야 한다는 뜻.
```

→ `check_b02_collinear()` 가 대입 판정과 기울기 판정이 세 점 조합 100,842가지에서
   항상 일치함을 확인한다.
